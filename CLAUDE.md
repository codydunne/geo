The viewer is deployed by `.github/workflows/pages.yml` (upload-pages-artifact
of `web/`; one-time repo setting: Pages -> Source: GitHub Actions). Locally run
`uv run scripts/serve.py`, which mounts `web/` at `/geo/` and serves
`index.html` for every non-asset path like production does; `file://` and a
plain `python -m http.server` are unsupported by design.

Checks: `node --test`, `corepack pnpm typecheck`, `uv run tests/smoke.py`
(browser, see its docstring for one-time setup), `ruff`/`ty` on `scripts/`.
`web/_/maps.json` is generated by `uv run scripts/collect_maps.py`; edit
`scripts/maps-overrides.json`, never the JSON output.

Never delete `web/_/maps.json` to regenerate: the collector reuses published IDs from it (shared `&m=` links depend on them); retire an entry with `"drop": true` in the overrides.
Anything derived from the URL (e.g. `a=`) reaches the DOM only as text: `textContent`, or a text node for Leaflet popups (Leaflet inserts strings as HTML).
Collector sources: GeoHack = `Template:GeoTemplate` wikitext (region ISO codes come from `id="GEOTEMPLATE-XX"` divs); OpenSwitchMaps `maps.js` is regex-parsed, never executed. Parse patterns use JS `(?<name>…)` groups; Python checks them as `(?P<name>…)`.
Review: `coderabbit review --agent --committed --base-commit <sha> -c CLAUDE.md` (2–6 min; prose docs: `--include-untracked --dir docs`).
