Run locally with `uv run scripts/serve.py` (serves `index.html` for every non-asset `/geo/` path, like production); `file://` and a plain `python -m http.server` are unsupported by design.
Checks: `node --test`, `corepack pnpm typecheck`, `uv run tests/smoke.py` (browser, see its docstring for one-time setup), `ruff`/`ty` on `scripts/`.
`web/_/maps.json` is generated by `uv run scripts/collect_maps.py`: edit `scripts/maps-overrides.json` (keys are tabled in README), never the output.
Never delete `maps.json` to regenerate: the collector reuses published IDs from it, and shared `&m=` links depend on them.
Retire a dead service with `"id"` + `"disabled": true`; `"drop": true` only to remove it outright.
Anything derived from the URL (e.g. `a=`) reaches the DOM only as text: `textContent`, or a text node for Leaflet popups (Leaflet inserts strings as HTML).
Collector: region ISO codes come from GeoTemplate's `id="GEOTEMPLATE-XX"` divs; OpenSwitchMaps `maps.js` is regex-parsed, never executed.
Parse patterns use JS `(?<name>…)` groups; Python checks them as `(?P<name>…)`.
