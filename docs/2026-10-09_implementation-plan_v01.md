## 2. `maps.json` schema

One fetch carries both the maps and the region table.

```json
{
  "v": 1,
  "src": {"gh": "GeoHack Template:GeoTemplate, CC BY-SA 4.0", "osm": "OpenSwitchMaps(Web) maps.js, MIT"},
  "maps": [
    {"id": "osm", "n": "OpenStreetMap", "c": "Main",
     "u": "https://www.openstreetmap.org/#map={z}/{lat}/{lon}",
     "p": ["openstreetmap\\.org/.*#map=(?<z>\\d+)/(?<lat>-?[\\d.]+)/(?<lon>-?[\\d.]+)"],
     "s": ["gh", "osm"]},
    {"id": "alltrails", "n": "AllTrails", "c": "Outdoor",
     "u": "https://www.alltrails.com/explore?b_tl_lat={n}&b_tl_lng={w}&b_br_lat={s}&b_br_lng={e}"},
    {"id": "os-uk", "n": "Ordnance Survey", "c": "Regional", "r": ["GB"], "u": "…"}
  ],
  "regions": {"GB": [-8.65, 49.86, 1.77, 60.86]}
}
```

Keys are one or two letters because the file is fetched on every visit.
`n` name, `c` category, `u` link template, `p` optional parse patterns, `r` optional region list (ISO 3166-1 alpha-2 codes or an inline `[w,s,e,n]` bbox), `s` sources.

**Placeholders** are a fixed vocabulary, each computed once in `geo.js`:

| Placeholder | Value |
|---|---|
| `{lat}` `{lon}` | Decimal degrees, as canonicalized |
| `{z}` | Integer OSM zoom |
| `{scale}` | `1693 · 2^(18 − z)`, the inverse of GeoHack's `osmzoom` formula |
| `{alt}` | Camera altitude in metres for Earth-style viewers |
| `{w}` `{s}` `{e}` `{n}` | Web Mercator viewport bbox for a 1024×768 px view at `z`; `lat` is clamped to ±85.0511° first, as Leaflet does, so the poles give finite bounds |
| `{a}` | URL-encoded label, empty if absent |

Any other `{…}` in a template is a collector bug, which the test suite catches.
The `{alt}` formula must be checked against one Google Earth link before release, because the constants seen in the wild differ.

**Parse patterns** are JavaScript regex source strings with named groups.
The allowed groups are `lat`, `lon`, `z`, plus a few alternatives for zoom: `m` (metres of view span) and `zf` (fractional zoom).
Each alternative is turned into `z` by one function in `geo.js`.
This keeps parsing in JSON, as the requirements ask.
The tradeoff: OpenSwitchMaps parsers that do more than one regex plus a unit conversion (for example, multi-branch Google parsing, or bbox-to-zoom) do not fit this format.
The collector translates the regex-only parsers automatically and reports the rest.
The ones that matter, Google Maps and Apple Maps, get hand-written patterns in the overrides.
**Decided:** the JSON approach (§8, D1).

## 3. Client (`web/_/geo.js`, `web/_/app.js`, `index.html`)

### 3.1 Input → state

`parse(raw) → {lat, lon, z?, m?, a?} | null`. It is a pure function, so it can run under `node --test`.

1. The input is the pathname suffix after the base, concatenated with `location.search` and `location.hash`.
   Concatenation matters: for `/geo/https://www.google.com/maps/search/?api=1&query=…` the embedded URL's query sits in `location.search`.
   With an empty suffix, the input is `location.search` minus its leading `?`, else `location.hash` minus `#`.
   Decode it once.
   Accept `https:/` as well as `https://`, in case a proxy collapses `//`.
2. Split the trailing `&z=`, `&m=`, and `&a=` params from the head with `URLSearchParams` semantics.
   The head may itself be a URL that contains `&`, so params are peeled from the end only while they match `^(z|m|a)=`.
3. Try the head against, in order:
   - plain `lat,lon`
   - `geo:` URIs (`geo:lat,lon[;u=…][?z=…]`)
   - DMS and hemisphere text (`42°21′52.8″N 71°7′52.7″W`, `42.36 N 71.13 W`; accept `'` `"` `′` `″` and spaces)
   - Google `place/`, `search/?api=1&query=`, `@?api=1&map_action=map&center=`, and `@lat,lon,Nz` forms
   - GeoHack `geohack.php?params=` in `D;D`, `D_N_D_W`, `D_M_…`, and `D_M_S_…` forms.
     GeoHack's field-count zoom heuristic (see [`2026-10-09_geohack-zoom.md`](2026-10-09_geohack-zoom.md)) is ignored. These URLs carry no zoom, so `z` defaults to 15; a `_dim:` or `_scale:` suffix is converted to `z`.
   - every `p` pattern in `maps.json`
4. Normalize, then validate.
   First wrap `lon` into [−180, 180), since longitudes past the antimeridian are common in panned map URLs and unambiguous.
   Then require `|lat| ≤ 90` and both values finite.
   Clamp `z` to [0, 21].
   A `lat` out of range is an error state, never silently clamped, because it signals a misparse.

### 3.2 Canonicalization

`canonical(state) → "/geo/<lat>,<lon>[&z=][&m=][&a=]"`.
Coordinates keep the digits as entered and are truncated (not rounded) past 6 decimals.
Number formatting goes through strings, not floats, so that `42.3646` stays `42.3646`.
`z=15` and empty params are dropped.
`a` is percent-encoded with `encodeURIComponent`, keeping `,` readable.
The URL is applied with `history.replaceState` on load, and again on pin drag or zoom end.

### 3.3 Base path

Assets cannot use relative paths, because `/geo/https://www.google.com/maps/place/…` has extra segments.
They cannot use absolute `/geo/_/` paths either, because the local server mounts differently.
`index.html` therefore starts with one inline script that writes `<base href="/geo/">`.
`scripts/serve.py` serves `web/` at `/geo/` and returns `index.html` for unknown paths, so local and production routing match, including reloads of the path form.
CLAUDE.md's local-run line changes to `uv run scripts/serve.py`.

### 3.4 UI

The UI is a single column on mobile and two columns at ≥ 48 rem (map on the left, list on the right).

- **Header row:** an input box (paste any URL, coordinates, or address, then Enter), Copy link, Share (shown only if `navigator.share` exists), and My location.
- **Leaflet map**, about 40vh on mobile, with OSM tiles and attribution as the tile policy requires.
  The pin is draggable, and its popup shows `a`.
  `moveend`/`dragend` update the state and re-render the links.
- **Featured map**, shown when `m` is set: the map's card is pinned at the top with an Open button. There is never an auto-redirect.
- **Search box** filtering by `n` and `c`.
- **List** grouped by `c`.
  Regional maps appear only when the point falls in an `r` bbox.
  Links are plain `<a href>` elements, refreshed on state change, so long-press and middle-click work.
- **Attribution footer:** GeoHack (CC BY-SA), OpenSwitchMaps (MIT), Leaflet, OSM, and Nominatim.

### 3.5 Nominatim

Geocoding runs only when `a` is present and coordinates are absent.
It makes one `fetch` to the `geocoder` URL template stored at the top level of `maps.json` (initially `https://nominatim.openstreetmap.org/search?format=jsonv2&limit=1&q={a}`), so the provider can be switched by a data change, as the Nominatim policy asks.
The browser sends the referrer, which satisfies the identification rule; a custom User-Agent cannot be set from a browser.
On success the URL is canonicalized with coordinates, so reloads never trigger a second lookup.
A `localStorage` map from `a` to coordinates (wrapped in try/catch) covers back-navigation to the bare `?a=` form.
There is no autocomplete, which the Nominatim policy forbids.
A failed lookup shows a message and an empty map. It does not retry.

## 4. Collector (`scripts/collect_maps.py`)

The script is a PEP 723 uv script with deps `httpx`, and is run as `uv run scripts/collect_maps.py`.
It writes `web/_/maps.json` deterministically: sorted, stable key order, and `indent=1` so diffs stay readable.
Run it, review the diff, and commit by hand.

1. **GeoHack:** fetch `https://en.wikipedia.org/w/index.php?title=Template:GeoTemplate&action=raw`.
   This wikitext is the source of GeoHack's link list.
   It currently holds about 450 URLs, a "Popular" block, and a `regional` table keyed by ISO codes.
   Then:
   - Extract `[url label]` links and their section headings.
   - Map placeholders: `{latdegdec}` → `{lat}`, `{londegdec}` → `{lon}`, `{osmzoom}` → `{z}`, `{scale}` → `{scale}`, `{title}`/`{titlee}` → `{a}`.
   - Drop links that use `{{#expr:}}`, UTM, `{pagenamee}`, `{params}`, or `{language}`, and log them with counts.
     GeoHack's own `{zoom}` placeholder is a different unit; check its definition before mapping it, and drop it until then.
   - Take region codes from the regional table's row headings.
2. **OpenSwitchMaps:** fetch `maps.js` from both repos at a pinned commit SHA (recorded in the output's `src`).
   Then:
   - Extract each entry's `name`, `category`, and the template literal returned by `getUrl`, rewriting `${lat}`, `${lon}`, and `${zoom}`.
   - Extract regex-only `getLatLonZoom` bodies into `p` with named groups.
   - Entries whose `getUrl` computes anything beyond substitution are reported for manual handling in the overrides, not guessed.
   - Parsing is regex over the JS source, not JS execution. The script never runs third-party code.
3. **Merge and dedupe:** the key is the template's host plus path with placeholders normalized.
   Name and category conflicts favour OpenSwitchMaps, since its categories are terser. `s` records every source.
4. **Overrides** (`scripts/maps-overrides.json`) are applied last.
   They hold, keyed by dedupe key or `id`:
   - curated `id`s
   - corrected templates and patterns
   - RideWithGPS (`https://ridewithgps.com/routes/new?center={lat}%2C{lon}&zoom={z}`, verified)
   - AllTrails (bbox placeholders)
   - mapfwd extras
   - `"drop": true` for dead services
5. **ID stability:** a published `id` never changes.
   The collector reads the previous `web/_/maps.json` and reuses its `id` for any entry with the same dedupe key.
   Only new entries get auto-slugs, which are kebab-case names deduped with a numeric suffix.
   A removed upstream entry is kept until it is explicitly dropped, and the summary reports it.
6. **Regions:** country bboxes come from Natural Earth admin-0 (public domain), via a pinned GeoJSON URL.
   Bboxes are computed in the script, rounded to 2 decimals, and limited to codes that some map references.
   Bboxes over-include near borders and for countries with antimeridian or overseas territory spans.
   Showing an extra regional map is an acceptable failure; the antimeridian case is handled by splitting into two boxes.
7. **Self-check:** an `assert`-based `check()` runs after writing.
   It confirms that every template uses only the fixed vocabulary, and that IDs are unique and a superset of the previous file's minus IDs explicitly marked `"drop": true`.
   Patterns are JS regex syntax (`(?<name>…)`, which Python `re` rejects), so the collector does not compile them; `tests/geo.test.js` does, with Node.
8. **Report** printed at the end: counts per source, new/removed entries, dropped links and the reason for each.

mapfwd is not scraped.
A one-time comparison of its service list is in Appendix A; it found no gaps.

## 6. Open items with proposed resolutions

| Item | Proposed resolution |
|---|---|
| Cloudflare collapsing `//` in `/geo/https://…` | The parser accepts `https:/` regardless (§3.1). After deploying the rule, `curl -sI` the Google example and record the result in the README. |
| Transform Rule expression | Rewrite path, dynamic: when `starts_with(http.request.uri.path, "/geo/") and not starts_with(http.request.uri.path, "/geo/_/")`, rewrite to `/geo/`, preserving the query. Verify the exact field names in the dashboard before writing them into the README. |
| Nominatim policy | §3.5: one request per page load at most, no autocomplete, cache by canonicalization plus `localStorage`, referrer as identification. |
| Region data source | GeoHack's regional table supplies the codes, and Natural Earth supplies the bboxes (§4.6). |
| `{alt}` and GeoHack `{zoom}` units | Verify against live links before enabling the affected maps. Until then they are dropped by the collector. |

## 7. Order of work

1. `geo.js` + `tests/geo.test.js` (parser and canonicalizer, against the requirement examples).
2. `collect_maps.py` + overrides → first `maps.json`; review the dropped/unhandled report.
3. `index.html`, `app.js`, `style.css`, fonts, Leaflet, `serve.py`.
4. `pages.yml` 404 copy step, README, LICENSE.
5. Deploy, create the Cloudflare rule, run the `//` check, then close the open items in `requirements.md`.

## 8. Decision log

Each entry records the conservative choice taken and the alternative not taken.

| # | Decision | Alternative |
|---|---|---|
| D1 | Parse patterns live in JSON as regex with named groups; complex OpenSwitchMaps parsers are reported, not ported. | Vendor OpenSwitchMaps' `getLatLonZoom` functions as an MIT-attributed JS module, covering the long tail at the cost of DOM assumptions and code in the payload. |
| D2 | Work on branch `impl`, not `main`. | Commit directly to `main`. |
| D3 | Vendor Leaflet 1.9.4 into `web/_/leaflet/`. | Pinned cdnjs URL; smaller repo, but the site would no longer be self-contained. |
| D4 | `404.html` is copied from `index.html` in `pages.yml`. | Commit both files and keep them in sync by hand or by test. |
| D5 | Geocoder URL comes from `maps.json`. | A separate `config.json`; one more fetch for one value. |
| D6 | `index.html` has a static `<base href="/geo/">`, since `serve.py` mounts at `/geo/` too. | The inline script in §3.3 that computes the base; only needed if the site moves to another path. |
| D7 | The collector uses only the standard library (`urllib`). | `httpx`, as §4 planned; no benefit for a handful of GETs. |
| D8 | GeoHack links using `{zoom}` (41) and other placeholders (`{span}`, UTM, OSGB, CH1903, …) are dropped and counted in the report. | Implement `{zoom}` = `int(18 − log(scale))` clamped to [0, 9]; the GeoHack docs do not say which log base, so it needs one live comparison first. |
| D9 | `{language}` in GeoHack links becomes `en`. | Drop those links (22), or use the browser language. |
| D10 | Google, `#map=`, and `center=…&zoom=` parse patterns are built into `geo.js`, not stored in the overrides. | Store them as `p` patterns on the `google` entry; that makes the required input forms depend on generated data. |
| D11 | Only `.woff2` fonts are shipped. | Also ship `.woff`, for browsers older than about 2016. |
| D12 | No `{alt}` placeholder: nothing needs it once GeoHack's `{altitude}` link (one) is dropped. | Add `alt = max(1, ⌊scale · 143 / 10⁶⌋)` per the GeoHack docs. |
| D13 | GeoHack's "International waters" (`XZ`) maps are shown everywhere; `AQ`/`XS`/`XN`/`SJ` get hand bboxes; `KO` is treated as `KR`. | Hide `XZ` maps entirely; or compute land/sea, which needs coastline data. |
| D14 | Omniscale's upstream template (`…/{lon}3857/B`, a missing `/`) is overridden to `…/{lon}/3857/B`. This is not verified against the live site. | Drop the entry until verified. |
| D15 | Geocoder coordinates are truncated like typed input; dragged-pin and geolocation coordinates are rounded to 6 decimals. | Round everything, or truncate everything. |
| D16 | Browser smoke test via Playwright's headless Chromium (`tests/smoke.py`), with Nominatim mocked and tiles blocked. | No browser test; or drive the installed Windows Chrome. |
| D17 | OpenSwitchMaps entries whose `getUrl` computes values (41 per repo) are skipped, except six notable ones re-added by hand (Google Satellite, Street View, Ventusky, Yelp, Worldview, Omniscale). | Hand-port all 41. Most are OSM QA tools or Japan-only, and GeoHack covers several. |
| D18 | Parse patterns that cannot read back their own map's link (5) are dropped by the collector. | Hand-fix each pattern in the overrides. |
